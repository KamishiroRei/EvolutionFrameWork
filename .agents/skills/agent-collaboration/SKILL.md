# 协作与独立审核

按任务的实际收益和授权选择是否分工。工具、模型和消息接口以当前宿主提供的能力为准。主控承担全局取舍、整合和交付。

交接包括原始目标、有效约束、相关材料、写入范围和产物返回入口。共享源码、编辑器与构建输出明确归属。接手时先核对在途操作和已有成果。消息投递或执行结果未知时，查实际会话和消息状态再决定是否重试。

独立审核从用户的原始要求、原始参考及已认可的设计取得标准。提供完整成果和实际观察入口，让审核者自行判断。设计负责完整方案，执行负责产物和修订，审核负责依据与偏差。阶段目标、作者自评和技术成功只能作为背景，审核范围由原始要求决定。

主控回收实际产物、可定位的证据和仍待处理的事项。分别说明作者完成、独立审核和用户接受。发送消息、创建外部会话和委托有副作用的动作沿用户授权执行。
