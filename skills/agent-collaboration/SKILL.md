# 协作与独立审核

按任务的实际收益和授权选择是否分工。工具、模型和消息接口以当前宿主提供的能力为准。主控承担全局取舍、整合和交付。

交接包括原始目标、有效约束、相关材料、写入范围和产物返回入口。共享源码、编辑器与构建输出明确归属。接手时先核对在途操作和已有成果。消息投递或执行结果未知时，查实际会话和消息状态再决定是否重试。

独立审核从用户的原始要求、原始参考及已认可的设计取得标准。提供完整成果和实际观察入口，让审核者自行判断。设计负责完整方案，执行负责产物和修订，审核负责依据与偏差。阶段目标、作者自评和技术成功只能作为背景，审核范围由原始要求决定。

主控回收实际产物、可定位的证据和仍待处理的事项。分别说明作者完成、独立审核和用户接受。发送消息、创建外部会话和委托有副作用的动作沿用户授权执行。

## 审核监督

结合当前任务和语境识别启用意图与审核对象。“启用审核会话”“开个审核会话”“让独立会话监督”等请求，启用针对当前任务的独立监督，包括新建独立顶层审核会话、观察成果、核实执行、往返反馈及相关方法迭代。审核会话须有独立 ID 和干净历史，禁止用 subagent、任务内子代理或旧制作历史的 fork 代替；新建后的专用会话持续负责本任务复审。对象从当前任务或用户指定会话确定，确实无法定位时只补问审核对象。交接保留用户启用的原话和来源，各平台按实际会话能力、模型设置和接口接入。

按实际进展推进以下工作，新完整成果或用户指导出现后接续复查。

1. 交接原始目标、有效要求、原始参考、认可设计和最新指导，以及执行会话、正式源、当前成果与相关技能入口。保留认可的具体范围。
2. 核对最新成果版本和实际使用入口，观察完整画面、动态或功能表现，按原始目标判断差距。作者状态、自评和工具成功分别记录，质量结论来自实际成果。
3. 与执行会话核实当前版本、未完成项、做法及原因，按需要检查实际实现、工具和读取链，判断偏差来自执行、方法还是实际条件。
4. 根据用户当前改动意图和原始目标，推导案例背后的同类成因、影响及必要联动，主动补齐相关修正，接续已认可与有效成果。说明应改变哪一层、改后呈现什么，保留未被否定且不受问题影响的部分。纠偏范围依据实际问题，不因同属一个专业或早期全面改造就要求整套重做；整体替换确有必要时说明原因和关键取舍。执行方融入原制作表继续制作，审核方结合原始目标与本轮交付独立判断。
5. 用户指导或实际纠错形成稳定的选型依据、技术做法或工具经验时，沿[知识管理](../knowledge-management/SKILL.md)融入所属技能和相交入口。项目标杆留在项目，临时参数和进度留在任务，相交文件明确写入者。用后续实际制作检验方法修订。
6. 同一目标下，执行方将成果作为当前约定目标的完成版本，正式提交用户或独立审核作交付判断，才算一次交付；连续三次这样的交付均被判为不合格时，审核主动组织旧执行之外的第三方完整核实、纠正方法并重排计划，然后开启独立的新执行会话。启用本流程包含达到该条件后的新执行会话与必要交接授权。

交付次数按实际提交成果的用途判断，不按消息或工具调用次数计数。制作中的探索、调试、工具失败、自我纠错、过程预览、局部修订和进度讨论均不计入；同一份交付的多个问题或多轮反馈只计一次，修订后重新正式交付才形成下一次。已有计数混入过程试错时，按实际交付更正，保留有效成果与上下文。明显失效的方法在当前制作中及时调整；用户明确要求提前重整时，按其要求执行。

第三方回到原始要求、最新用户裁定、原始参考、最新完整成果和真实责任源，独立核验关键前提、采用判断、方法与实现。沿当前任务记录整理一份自洽的交接说明，包含已确认事实、待核实判断、有效成果、应撤掉的错误前提、修订后的专业方法及按依赖重排的制作安排。

新执行会话使用独立上下文，先审视交接判断与现有做法，按真实来源核实并重整后制作。旧长对话和零散补丁不整包继承，有效成果和用户裁定继续保留。交接前收束相交写入与在途操作，交还共享资源，接续后仍按原始目标观察完整成果。

按实际情况说明已观察的结果、方法修订、未决事项和下一动作。技能已更新、执行已采用、成果已改善、独立审核达标及用户接受分别陈述，资料沿用当前任务记录。


## 一次性交接与单向接力

用户要求一次性交接时，旧会话收束自己派发的子任务、写入和在途操作，交还编辑器、媒体与其他共享资源，将原始要求、最新有效裁定、原始参考、当前完整成果、正式源、已确认事实、待核实判断、在途状态与未完成项一次性写入既有任务区的完整交接说明，随后退出后续协作。交接沿用已有资料，不追加冻结、哈希、测试、复拍或核验包。

新审核会话依据原始要求与实际成果独立重整，再由审核会话亲自使用宿主正式会话接口创建新的独立执行会话。新审核会话和新执行会话均不得向旧会话发送任何消息，不向旧会话追问、求确认、汇报或请求再次规划。必要信息从交接资料、原始参考与正式源取得。新审核与新执行之间按当前授权正常沟通，制作、重整和监督职责在新协作链中完成。

仅要求成品独审时，审核者对完整成果独立判断，制作方的施工目标、自评和收口压力不改变标准。审核监督中的执行核实和方法迭代服务于原始目标，技术解释不抵扣成果偏差。
