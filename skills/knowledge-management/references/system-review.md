# 系统检阅

用于维护整个 AGENT/SKILL 系统，或在规则增长、重复、失效和实际执行偏差影响工作时检查相关范围。根据本次目标确定范围与交付。

1. 从宿主实际加载配置定位全局规则、项目覆盖、技能目录、预设与插件。全量检阅覆盖范围内的生效正文，按真实消费者检查大型资料和脚本。双向核对入口指向的文件和文件的调用方。
2. 判断内容是否有独立价值、适用范围是否正确、规则是否冲突。比较职责和消费者，再决定保留、合并、归回项目或退役。技能数量和篇幅服从使用价值。
3. 有实际错例时按当时知道的情况回放。分别看首次表达的目标、探查所得依据和实施前汇报的做法。把拟议方案放进正常场景和问题场景，检查用户要求的修正与原有正常行为能否同时成立。修正最早诱发偏差的规则，再换一个同类场景复核。
4. 迁移时同步更新描述、入口、链接、索引、脚本相对路径和加载配置。核对实际文件、链接目标和独立副本的身份，保护仍被其他项目或宿主消费的内容。托管内容沿其正式配置变更。
5. 完成所需正文和相交入口修改后直接交付，不追加格式测试、链接扫描、加载复验或调用测试。用户明确要求检阅时，只查所指问题，报告实际改动。

有多个相关修改时，用同一份制作表接续发现、调整与核对。把当前目录清单和进度留在任务区。长期文档留下稳定规则和正式导航。
